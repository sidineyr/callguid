## Português

CallGuide Desktop para Windows x64, Linux x64 e macOS Intel/Apple Silicon. Baixe o arquivo correspondente em Assets, extraia a pasta inteira e abra o aplicativo. O diretório desktop do repositório contém as instruções e o código.

Pratique palavras com mouse ou caneta de mesa digitalizadora. A pressão real depende do dispositivo e do driver; o mouse usa largura constante. Conteúdo offline, sem conta ou anúncios. A interface está em português.

Os pacotes não têm certificado comercial de assinatura. No macOS a assinatura é ad-hoc e não há notarização Apple; políticas do sistema podem impedir a abertura. Não desative proteções do sistema. Os testes de execução nas quatro plataformas são automatizados em runners nativos, não testes manuais com uma mesa física.

## English

CallGuide Desktop for Windows x64, Linux x64, and macOS Intel/Apple Silicon. Download the matching asset, extract the entire folder, and launch the app. The repository's desktop directory contains the source and instructions.

Practice words with a mouse or a drawing-tablet pen. Real pressure depends on the device and driver; mouse strokes use constant width. Offline, no accounts or ads. The interface is in Portuguese.

Packages do not have a commercial signing certificate. The macOS signature is ad-hoc, without Apple notarization; system policies may prevent launch. Do not disable system protections. Runtime tests on all four platforms are automated native-runner tests, not physical drawing-tablet tests.
